## 五、一个已知退化边界（不可达，但记一笔）

决斗门槛是 `n // 2`，当分母 `n == 1` 时门槛为 0，会「0 票通过」。n=1 在实战里到不了（六个席位没有当前牌时 A、B 必然已整席出局，好人早就获胜并结束对局）。**已按建议加防守兜底**：`threshold = max(1, n // 2) if duel else n // 2 + 1`（`engine.py` 的 `resolve_vote`）。
