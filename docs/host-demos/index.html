同一套七双规则，三种主持方式。先比较操作逻辑，再决定正式界面怎么改。

交互原型 · 全部为虚构数据 · 不连接真实对局
A / 推荐起点

流程领航

把「现在该做什么」放在最前面。谁还没交、为什么不能推进、下一步公开什么，一屏说清。

试用：模拟剩余玩家提交 → 自动进入审阅 → 确认公布。

打开流程领航 →
B / 全局优先

七席魔典

七个席位直接铺在桌面。点人看双牌和状态，避免来回翻管理页面；私密牌面可以集中遮挡。

试用：选择席位 → 遮挡牌面 → 切换投票演示。

打开七席魔典 →
C / 裁定优先

裁定收件箱

把需要你决定的事与系统记录分开。看依据、选结果、确认影响；不把自动规则变成主持人工作。

试用：处理裁定 → 模拟版本冲突 → 重新确认。

打开裁定收件箱 →
